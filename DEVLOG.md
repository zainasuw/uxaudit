# UXAudit development log

I asked Claude Code to help me build a browser-based tool that could analyze websites and provide useful feedback. I wanted something straightforward to use, where someone could paste a website URL and receive a report.

Claude helped me plan and implement the application using TypeScript, Node.js, and Playwright. During development, I decided to focus on automated checks and screenshot capture rather than attempting to build the entire AI-powered design critic at once.

I tested the application using real websites, reviewed the results, and decided to leave more advanced design analysis and AI integration for the next artifact.
